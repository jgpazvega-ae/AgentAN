Pago con tarjeta

En México no se puede cobrar un recargo por pagar con tarjeta. Lo permitido es un precio de lista igual para cualquier forma de pago y un descuento para efectivo o transferencia. Las tarifas de arriba son el precio con descuento; el precio de lista se calcula para cubrir la comisión de la terminal (Mercado Pago cobra alrededor de 3.5% + IVA; revisa tu plan). Pon 0 para no usar descuento.
